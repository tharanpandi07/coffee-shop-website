# ☕ COFFE. — Premium Coffee Shop Website

A modern, cinematic coffee shop website built with React.js and Vite. Designed with an elegant aesthetic, smooth animations, immersive visuals, and a responsive layout to deliver a premium café experience.

## 🌐 Live Demo

🔗 **Live Website:** https://coffee-shop-website-swart-one.vercel.app/

## ✨ Features

- 🎬 **Cinematic Hero Section** — Immersive background video and engaging landing page.
- 🧭 **Interactive Navigation** — Navigate between Home, Our Story, Menu, Gallery, and Contact sections.
- ☕ **Coffee Menu** — Showcase coffee varieties and café offerings.
- 🖼️ **Gallery Section** — Display coffee shop visuals in an attractive layout.
- 📖 **About Section** — Introduce the café and its story.
- 📩 **Contact Section** — Provide contact information for visitors.
- 🦶 **Custom Footer** — Brand information, navigation links, opening hours, and social links.
- 📱 **Responsive Design** — Adapted for desktop and mobile screens.
- ✨ **Modern UI** — Clean typography, premium styling, and engaging visual elements.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Build Tool:** Vite
- **Styling:** CSS3
- **Icons:** Lucide React
- **Version Control:** Git & GitHub
- **Deployment:** Vercel

## 🚀 Getting Started

### Prerequisites

Install the following before running the project:

- [Node.js](https://nodejs.org/)
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/tharanpandi07/coffee-shop-website.git
```

**2. Navigate to the project directory**

```bash
cd coffee-shop-website
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the website**

Visit the local URL shown in your terminal, usually:

```text
http://localhost:5173
```

## 🏗️ Build for Production

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## 🌍 Deployment

This project can be deployed using **Vercel**.

1. Import the GitHub repository into Vercel.
2. Select Vite as the framework preset.
3. Set the build command to `npm run build`.
4. Set the output directory to `dist`.
5. Deploy the project.
